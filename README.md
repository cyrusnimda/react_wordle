## Technical Test Description: React.js (60 Minutes)

**Objective:**  
Develop a simple Wordle-like game using React.js. You may use Vite or any other React starter template. The focus is on code quality and functionality; styling is not important. Writing tests is a plus.

**Requirements:**
- Display a 5-letter word for the user to guess.
- Allow the user to input guesses (one per attempt).
- After each guess, show feedback for each letter:
  - Correct letter and position.
  - Correct letter, wrong position.
  - Incorrect letter.
- Limit the number of attempts (e.g., 6).
- Show a message when the user wins or loses.

**Bonus:**
- Implement basic unit tests for core logic (e.g., feedback calculation).

**Notes:**
- Use React functional components and hooks.
- You may use any libraries or tools (e.g., Vite, React Testing Library).
- Focus on clean, readable code and correct functionality.

**Time Limit:** 60 minutes
